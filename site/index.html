Install SpliceFS

Run one command, or add the repository yourself.

Every command is safe to run again. A second run repairs what is broken and changes nothing that works.

Packages are built for x86-64 and arm64.

Install with one command

curl
curl --proto '=https' --tlsv1.2 -fsSL https://packages.splicefs.org/install.sh -o ~/splicefs-install.sh &&
  sudo sh ~/splicefs-install.sh server
wget
wget -qO ~/splicefs-install.sh https://packages.splicefs.org/install.sh &&
  sudo sh ~/splicefs-install.sh server

Replace server with client or both.

Already root? Leave out sudo.

The script sets up the SpliceFS package source for your system and installs the package. It is safe to run again.

It is downloaded completely before it runs. To check it first, compare its SHA-256 with the one in the packages repository on GitHub:

Shell
sha256sum ~/splicefs-install.sh

Works on Debian, Ubuntu, RHEL, Rocky Linux, AlmaLinux, Amazon Linux, openSUSE and Alpine, on x86-64 and arm64.

Pick a system above.

Debian and Ubuntu

  1. Add the SpliceFS repository

    Shell
    # Add the SpliceFS signing key:
sudo apt-get update
sudo apt-get install -y ca-certificates curl
sudo install -m 0755 -d /etc/apt/keyrings
sudo curl -fsSL https://packages.splicefs.org/keys/splicefs.asc -o /etc/apt/keyrings/splicefs.asc
sudo chmod a+r /etc/apt/keyrings/splicefs.asc

# Add the repository to apt sources:
sudo tee /etc/apt/sources.list.d/splicefs.sources >/dev/null <<'EOF'
Types: deb
URIs: https://packages.splicefs.org/server/apt https://packages.splicefs.org/client/apt
Suites: stable
Components: main
Signed-By: /etc/apt/keyrings/splicefs.asc
EOF

sudo apt-get update

  2. Install

    Server
    sudo apt-get install -y splicefs-server
    Client
    sudo apt-get install -y splicefs-client

RHEL, Rocky Linux, AlmaLinux and Amazon Linux

  1. Add the SpliceFS repository

    Shell
    # Add the SpliceFS signing key:
sudo install -m 0755 -d /etc/pki/rpm-gpg
sudo curl -fsSL https://packages.splicefs.org/keys/splicefs.asc -o /etc/pki/rpm-gpg/RPM-GPG-KEY-splicefs
sudo chmod a+r /etc/pki/rpm-gpg/RPM-GPG-KEY-splicefs

# Add the repository:
sudo tee /etc/yum.repos.d/splicefs.repo >/dev/null <<'EOF'
[splicefs-server]
name=SpliceFS server
baseurl=https://packages.splicefs.org/server/rpm/$basearch
enabled=1
gpgcheck=1
repo_gpgcheck=1
gpgkey=file:///etc/pki/rpm-gpg/RPM-GPG-KEY-splicefs

[splicefs-client]
name=SpliceFS client
baseurl=https://packages.splicefs.org/client/rpm/$basearch
enabled=1
gpgcheck=1
repo_gpgcheck=1
gpgkey=file:///etc/pki/rpm-gpg/RPM-GPG-KEY-splicefs
EOF

  2. Install

    Server
    sudo dnf install -y splicefs-server
    Client
    sudo dnf install -y splicefs-client

openSUSE Leap

  1. Add the SpliceFS repository

    Shell
    # Add the SpliceFS signing key:
sudo install -m 0755 -d /etc/pki/rpm-gpg
sudo curl -fsSL https://packages.splicefs.org/keys/splicefs.asc -o /etc/pki/rpm-gpg/RPM-GPG-KEY-splicefs
sudo chmod a+r /etc/pki/rpm-gpg/RPM-GPG-KEY-splicefs
sudo rpm --import /etc/pki/rpm-gpg/RPM-GPG-KEY-splicefs

# Add the repository:
sudo tee /etc/zypp/repos.d/splicefs.repo >/dev/null <<'EOF'
[splicefs-server]
name=SpliceFS server
baseurl=https://packages.splicefs.org/server/rpm/$basearch
enabled=1
autorefresh=1
gpgcheck=1
repo_gpgcheck=1
pkg_gpgcheck=1
gpgkey=file:///etc/pki/rpm-gpg/RPM-GPG-KEY-splicefs

[splicefs-client]
name=SpliceFS client
baseurl=https://packages.splicefs.org/client/rpm/$basearch
enabled=1
autorefresh=1
gpgcheck=1
repo_gpgcheck=1
pkg_gpgcheck=1
gpgkey=file:///etc/pki/rpm-gpg/RPM-GPG-KEY-splicefs
EOF

sudo zypper --non-interactive refresh splicefs-server splicefs-client

  2. Install

    Server
    sudo zypper --non-interactive install splicefs-server
    Client
    sudo zypper --non-interactive install splicefs-client

Alpine

Run these as root.

  1. Add the SpliceFS repository

    Shell
    # Add the SpliceFS signing key:
wget -q https://packages.splicefs.org/keys/splicefs.rsa.pub -O /etc/apk/keys/splicefs.rsa.pub

# Add the repositories:
mkdir -p /etc/apk/repositories.d
printf '%s\n' https://packages.splicefs.org/server/alpine https://packages.splicefs.org/client/alpine \
  > /etc/apk/repositories.d/splicefs.list
apk update

  2. Install

    Server
    apk add splicefs-server
    Client
    apk add splicefs-client

After the install

The service is registered when the package is installed. It starts once its configuration file exists:

  • Server: /etc/splicefs/server/config.yaml Server configuration
  • Client: /etc/splicefs/client/config.yaml Client configuration
